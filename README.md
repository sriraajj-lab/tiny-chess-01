# tiny-chess-01 entry

An entry to make.fun's [Build the strongest chess engine in 4 KB of Python](https://make.fun/bounty/tiny-chess-01) bounty.

A chess engine in 4 KB of Python: negamax alpha-beta with quiescence,
a transposition table, tapered piece-square evaluation and a fixed
60,000-node search, playing the make.fun gauntlet over its HTTP env.

MIT licensed. Built with Muse; the readable source is packed into
main.py with the kit's makefun compress.
